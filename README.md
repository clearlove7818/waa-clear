# waa-clear

`waa-clear` 是一个独立的中文表达技能：保留准确含义，减少阅读和操作负担。适合希望 AI 直接回答、清楚交付，同时保留完整解释的使用者。规则见 [SKILL.md](SKILL.md)。

它选择性改编 STC 的自然中文与事实保护，以及 i-have-adhd 的操作分步和低负担交互；没有拼接两套完整规则，也不假设或诊断读者患有 ADHD。

## 如何使用

让支持技能的 Agent 读取 `SKILL.md`，再明确提出当前任务。例如：

```text
用 waa-clear 改写下面这段中文，保留事实、否定、权限和不确定性：
只读成员通常不能导出；管理员可能需要另行授权。
```

```text
按 waa-clear 整理这次任务回执，分清已验证结果和未验证部分。
没有需要我处理的事就直接结束。
```

普通调用仅覆盖当前任务及后续补充。仅仅用中文聊天不等于请求启用。明确要求中文表达、改写、审阅、精简说明或整理回执时，Agent 可根据技能描述选用它；实际发现机制取决于宿主平台。

需要会话范围时，明确说「本次会话默认使用 waa-clear」。结束时说「停止使用 waa-clear」。这不写入持久配置，也不承诺跨会话生效。无需会话默认时，按任务调用即可。

## 表达示例

以下是说明性示例，不是实测模型效果。

| 任务与已知条件 | 表达方式 |
| --- | --- |
| 问：导出按钮在哪？已知在报告页右上角。 | 导出按钮在报告页右上角。 |
| 只知道请求失败，怀疑网络中断。 | 请求失败，原因尚未确定；网络中断是待核实的可能原因。 |
| 已生成预览，但没有验证手机显示。 | 预览已生成；手机显示尚未验证。 |
| 要求完整列出七个限制。 | 列出全部七项；需要时分组，不把后两项留到下轮。 |
| 没有测量数据，问迁移要多久。 | 目前无法可靠估计耗时。先说明缺少哪些影响估计的条件，不编造分钟数。 |

操作指导用编号写实际步骤；普通问答不凭空增加用户动作。可以详细解释，也可以只回答一句，篇幅由任务决定。

## 手动安装

这里只提供手动步骤，仓库不包含安装器、脚本或运行时依赖。安装前先查宿主平台当前的技能目录和加载方式；本项目没有验证所有平台。

1. 下载或复制本仓库，先检查 `SKILL.md` 及许可文件。
2. 在选定的技能目录中新建 `waa-clear` 文件夹。目标已存在时先停止，核对已有内容和归属，不直接覆盖。
3. 复制本仓库的五个根文件，保留 `SKILL.md`、说明和许可文件之间的相对位置；不要复制版本控制内部目录。
4. 按宿主平台要求刷新技能列表，再明确调用 `waa-clear`。用一个已知答案的问题检查：应直接回答，不虚构下一步，也不改变原有输出格式。

**安装不会自动启用本技能，也不会停用 STC、i-have-adhd 或 tech-doc。** 本项目不修改 `AGENTS.md`、`CLAUDE.md` 或其他默认配置。如果旧默认显式引用 STC 或 i-have-adhd，需要单独授权并核对范围后再迁移；不要同时加载三套表达技能作为竞争的默认规则。

未安装时，也可在单个任务中提供本文件夹的 `SKILL.md` 内容并明确要求使用。仅阅读说明或测试用例不构成对其他任务的启用。

## 与 tech-doc 配合

`tech-doc-style-chinese` 保持独立、可选，不随本仓库分发或安装。

- 中文技术文档、产品与界面文案适用且可用时，tech-doc 负责成品的专门结构、术语、称呼、标点和审阅模式；waa-clear 负责周围对话与共同的事实保护。
- 普通中文基线使用弯引号 `“”`；tech-doc 的适用成品可使用直角引号 `「」`。项目或用户明确约定优先，固定引文和机器字面量不做全局替换。
- tech-doc 不可用时，继续采用 waa-clear 基线，并说明未做完整 tech-doc 检查，不假装已经验证。

## 设计取舍

| 选择 | 原因与边界 |
| --- | --- |
| 问答给答案，操作给安全动作，交付给验证结果。 | 不把所有内容都变成给用户的作业。 |
| 在里程碑、阻塞、变化或恢复时展示状态。 | 可见清单已有的信息不再复述，普通回答不背诵背景。 |
| 只有真实需要时才给结尾动作。 | Agent 完成已授权工作；完成后不制造批准请求或新任务。 |
| 分组和句长是提示，不是硬上限。 | 完整列表、长解释、风险和例外不能因压缩而丢失。 |
| 估时需要执行者、条件和依据。 | 无依据时承认未知，保留不确定性与频率。 |
| 分清对话、文档、界面和 Agent 指令。 | 进度与回执规则不进入成品、代码、引文、法律文本或固定格式。 |
| 重复失败先查假设与证据。 | 不按固定轮数强制提问，也不盲目重复修改。 |

具体规则以 [SKILL.md](SKILL.md) 为准。用户请求、运行环境、项目规则与事实保护优先；这只是表达技能，不负责医疗建议、业务逻辑实现、权限授予或未经请求的字面量改写。

## 限制与维护

这是纯文本行为指引，不是强制执行器。静态检查只能检查文件结构和文字，不能证明模型服从；说明性示例也不是独立、盲测或跨模型效果证据。实际平台发现、会话持续性和真实读者体验需要在使用环境中验证。

本项目不包含 STC 的 CLI、规则目录、词典或检查器，也不声称完整兼容 STC。没有自动更新、默认规则迁移或自动安装能力。上游更新不自动改变本项目。
